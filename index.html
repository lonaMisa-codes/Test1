Need way more than your browser can handle?

This page is a convenient, zero-install demo. For tens or hundreds of GB (or TB), use the command-line tool this page is based on — it streams writes straight into the zip with no large in-memory buffers:

python randzip.py -n 4 -s 15360 -o huge.zip  # 4 x 15 GB = 60 GB extracted

See README.md in this repo for all options.

Built with randzip-cli · Runs 100% client-side via fflate, deployed with GitHub Actions + Pages.
